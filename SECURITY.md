## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us in a responsible manner.

Please do not report security vulnerabilities through public GitHub issues, as this could put the project and its users at risk.

Instead, please report the vulnerability privately by contacting the maintainers directly. You can typically do this by:
* Checking the commit history for maintainer email addresses.
* Looking for a dedicated security contact email address on the project's website or in the documentation.

When reporting a vulnerability, please provide:
* A detailed description of the vulnerability.
* Steps to reproduce the issue.
* Any potential impact or risk associated with the vulnerability.
* If possible, a proposed solution or mitigation.

We will endeavor to respond to your report promptly, investigate the issue, and provide a timeline for a fix. We will also coordinate with you on the public disclosure of the vulnerability once it has been resolved.

Thank you for your help in keeping our project secure!
